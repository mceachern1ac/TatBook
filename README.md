# TatBook

TatBook is a platform designed to showcase tattoo portfolios, connect artists with clients, and streamline the booking process.  
**Note:** This project is currently in development. All data and images are placeholders and do not represent real users or tattoos.

## About

TatBook aims to provide a modern, user-friendly platform for tattoo artists and enthusiasts. The project is currently in its early stages, with ongoing development and design iterations.

---

## Features

- Artist portfolio galleries
- Booking and scheduling system
- User profiles
- Search and filter functionality
- Responsive design
